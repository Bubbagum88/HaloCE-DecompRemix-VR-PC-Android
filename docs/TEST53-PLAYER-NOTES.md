# Test53 player notes

Private test build 1.0.20-test53 (Android code 65), after public v1.0.19.
Installs over v1.0.19 and keeps your data. Read the bundled guide's Test53
section ([TEST53-FIELD-GUIDE.md](TEST53-FIELD-GUIDE.md)) and test with
[TEST53-DEVICE-CHECKLIST.md](TEST53-DEVICE-CHECKLIST.md).

- Voice: the crash when speaking is fixed at its cause (a corrupted Opus
  table in the Quest build); needs your headset test.
- Network 26: current OpenCE servers can be joined; All compatible networks
  is the default.
- VR Settings → IMMERSION gathers every immersion option.
- Grabbing (NPCs, objects, vehicles), parkour (wall-run, wall-jump, grip
  climb) and manual reload were blocked by two defects that are now fixed;
  released NPCs recover within 5 s; body retention keeps bodies through
  campaign clean-ups. All of these need headset confirmation.
