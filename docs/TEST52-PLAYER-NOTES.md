# Test52 player notes

Test52 (1.0.20-test52, code64) is a private stabilization build. It fixes the
crash when talking in voice chat on Quest (v1.0.19/Test51), plus a related class
of build defects that garbled voice logs and some values on Quest/Android. See
[TEST52-FIELD-GUIDE.md](TEST52-FIELD-GUIDE.md) for the full notes,
[TEST52-CRASH-ANALYSIS.md](TEST52-CRASH-ANALYSIS.md) for the evidence, and
[TEST52-DEVICE-CHECKLIST.md](TEST52-DEVICE-CHECKLIST.md) for what to test.
Everything else from v1.0.19 is retained; it is not a public release.
